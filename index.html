Tentang Saya

Di Institut Teknologi Sumatera (2022–2026), saya mempelajari sains atmosfer dan keplanetan, dengan minat pada meteorologi, klimatologi, instrumentasi, observasi, serta komputasi ilmiah. Dalam tugas akhir, saya menggunakan sensor ultrasonik JSN-SR04T dan ESP32 untuk memantau tinggi muka air. Saya kemudian mengolah data pengukuran dengan Python, menyiapkan fitur untuk model XGBoost, dan menyajikan hasil prediksi melalui dasbor. Pada proyek DIY IoT Rover, saya memadukan ESP32, sensor BMP280 dan DHT11, serta ESP32-CAM untuk mengamati kondisi lingkungan.

Saat magang di bagian Instrumentation & Control PT PLN Nusantara Power UP Muara Tawar, saya ikut mengembangkan prototipe pemantauan lingkungan. Tugas saya mencakup pemeriksaan data sensor, visualisasi melalui ThingSpeak, pengujian perangkat, dan dokumentasi sistem. Pengalaman ini memberi saya kesempatan untuk mengikuti alur kerja dari pembacaan sensor hingga penyajian hasilnya.

Saya juga menjadi asisten praktikum untuk dua mata kuliah di ITERA. Pada praktikum komputasi atmosfer dan keplanetan, saya mendampingi mahasiswa mengolah data menggunakan Python dan Google Colab serta membantu saat program mereka mengalami kendala. Pada praktikum instrumentasi dan observasi, saya menyiapkan instrumen, mendampingi kegiatan pengamatan, dan membantu mengevaluasi tugas.

Di luar kegiatan akademik, saya memperoleh pengalaman operasional di Pocha Gang, Bandar Lampung. Saya mencatat persediaan, memantau kebutuhan pengisian stok, dan bekerja sama dengan tim dapur. Untuk memperkuat kompetensi teknis, saya mengikuti pelatihan pengolahan data dan machine learning melalui Kaggle serta sertifikasi FreeFlyer Level 1 dan Level 2 untuk simulasi orbit satelit. Pengalaman organisasi, pelatihan Microsoft Excel, dan dasar pengelolaan SDM melengkapi kemampuan kerja sama dan koordinasi saya.
